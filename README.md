# TMS — Task Management System

I built this as a full-stack task manager using the MERN stack. It allows individuals to create tasks, set priorities, assign deadlines, and monitor progress in a structured way. By providing a clear overview of pending and completed work, a task manager helps improve time management, reduce stress, and enhance overall productivity, making it an essential tool for both personal and professional use.

🌐 **Live Demo:** [https://tms-1-x0dt.onrender.com](https://tms-1-x0dt.onrender.com)


---

## What's inside

**Frontend**
- React 19 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui + Radix UI
- MUI (Material UI)
- React Router v7
- React Hook Form
- Recharts
- React DnD (drag and drop)

**Backend**
- Node.js + Express.js
- MongoDB + Mongoose
- JWT Authentication
- bcrypt for password hashing
- Morgan for HTTP logging

**Deployed on**
- Frontend → Render (Static Site)
- Backend → Render (Web Service)
- Database → MongoDB Atlas

---

## Features

-  Register and login with JWT-based auth
-  Full CRUD on tasks
-  Priority levels — High, Medium, Low
-  Analytics and charts
-  Dark mode
-  Works on mobile too

## A few things to know

- The free Render tier sleeps after 15 minutes of no traffic — the first request after that takes about 30–50 seconds to wake up. Totally normal.
